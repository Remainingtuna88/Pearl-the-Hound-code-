          Setup & backend notes
          1. Open this file in a browser. It starts in MOCK mode with a scripted ~4-minute simulation that loops. Nothing is fetched from the network in mock mode.
          2. To go live: set ROBOT_BASE_URL in the first <script> block, reload, click LIVE. Live mode is auto-reset to mock on every page load so a stale demo never masquerades as real.
          3. CORS is mandatory. The robot's HTTP server must return Access-Control-Allow-Origin: * (plus -Methods and -Headers) on every response and answer OPTIONS preflights. Otherwise every panel reads "unreachable" and the browser console says only "Failed to fetch".
          4. Endpoints: GET /api/state, GET /api/goals, GET /api/vision, GET /camera/stream, POST /api/target, POST /api/behavior, POST /api/recall. Full payload shapes with examples are in the comment block at the top of this file.
          5. Polling is every ms with a ms timeout. The Pi is busy; do not lower these.
